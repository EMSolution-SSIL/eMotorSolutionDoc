# Efficiency and Performance Map

Efficiency Map sweeps current and current phase for a PMSM electromagnetic analysis, then evaluates
efficiency, torque, output power, minimum current, maximum efficiency, and MTPV performance with `ems_motor_nt`.
In v0.7.0, the GUI supports analysis, performance calculation, result plotting, and single-point Motor ROM evaluation.

## Before you start

1. Set the coil resistance in `Stator > Conductor`.
2. Set iron-loss coefficients for the stator and rotor lamination materials.
3. Add `Analysis > PMSM > Efficiency Map`.
4. Configure Motion, Calculation Steps, and Current and Phase.

Enable `Use full electrical cycle` when iron loss is evaluated.

## Performance calculation

`Calculate efficiency map` provides the following `CalculationAPI` choices.

| CalculationAPI | Main result |
| --- | --- |
| `calculate_ntcurve` | Torque-speed characteristic |
| `calculate_efficiency` | Efficiency map |
| `calculate_pout_limit` | Output-limit curve |
| `calculate_min_current` | Minimum-current curve |
| `calculate_nt_force` | Force-related results |
| `calculate_max_efficiency` | Maximum-efficiency operating characteristic |
| `calculate_mtpv` | MTPV operating characteristic |

Each API has its own required artifacts. A missing CSV is not an error when the selected API produces JSON results only.

## Results and Performance Map

| File | Content |
| --- | --- |
| `Efficiency_Map_em2bm.json` | Full dq-grid behavior model |
| `efficiency_map_nt_input.json` | Input passed to `ems_motor_nt` |
| `efficiency_map_results.json` | Performance-calculation result |
| `efficiency_map_performance_map.json` | Two-dimensional map and per-point details |
| `efficiency_map_plot.csv` | Legacy CSV generated by supported APIs |

Use `Plot efficiency map` to select a Quantity and display the map. An unsupported major `schemaVersion` is rejected.

## Single-point Motor ROM

Specify Speed, Torque, and Control Strategy (`AUTO`, `MIN_CURRENT`, or `MAX_EFFICIENCY`) to evaluate one operating point.
An operating point outside the constraints is returned as `INFEASIBLE` and is distinct from an execution error.

## Status and notes

- `OK`: evaluation succeeded
- `INFEASIBLE`: evaluation completed but the point violates constraints
- API error: input, artifact, or custom-loss execution failed

Custom loss models are applied as post-processing to existing operating points; they do not search for new points.
See the [PMSM Efficiency Map API](../../api/Analyses/PMSM/PMSM_Efficiency_Map) for the Python API.
